# Архитектура DEARMO

## Паттерн

Иерархическая система с обратной связью: **планировщик (локальная Qwen)** → **маршрутизатор инструментов** → **агенты-исполнители** → **критик** → **review**. Критик может вернуть систему на дополнительный шаг.

Ключевое правило, на котором держится вся система:

> **LLM выбирает варианты, инструменты производят числа.**
> Модель никогда не возвращает значение — только индекс в списке, который собрали
> инструменты, плюс обоснование. Обоснование попадает в Evidence как `hypothesis`
> с указанием модели, а не как измерение.

Это даёт управление на естественном языке без риска выдуманных результатов.

## Где именно работает LLM

| Решение | Из чего выбирает | Что будет без LLM |
|---------|------------------|-------------------|
| Сценарии и сущности запроса | текст пользователя | эвристика по ключевым словам |
| Нормализация названия молекулы | «гефитиниб» → `gefitinib` | резервный разбор берёт только латиницу |
| Набор инструментов | каталог в `prompts/tool_router.txt` | фиксированный маршрут сценария |
| Мишень | мишени из измерений BindingDB | первая по силе связывания у человека |
| Структура PDB | кандидаты поиска RCSB с метаданными | лучшее разрешение |
| Достаточность ответа (критик) | собранные Evidence | шаг пропускается |
| Пересказ | собранные Evidence | перечисление измерений |

Любой из пунктов может деградировать независимо: без Ollama система продолжает работать, честно помечая, что выбор сделан эвристикой.

## Роли агентов

| Агент | Назначение | Вызывает LLM |
|-------|------------|--------------|
| planner | Сценарии и сущности | да |
| tool_router | Набор инструментов под сценарий | да |
| data_agent | BindingDB, ChEMBL, PubChem, RAG; выбор мишени | да |
| structure_agent | Кандидаты RCSB и выбор структуры | да |
| chemistry_agent | RDKit-дескрипторы и фильтры | нет |
| docking_agent | AutoDock Vina по паре структура+лиганд | нет |
| pocket_worker | Один карман = один воркер (параллельно) | нет |
| analysis_agent | Сравнение карманов, тепловая карта | нет |
| validation_agent | Геометрия позы | нет |
| writer | `report.md` из Evidence | нет |
| critic | Полнота ответа, запрос доп. шага | да |
| review_agent | Контракт Evidence и чисел в тексте | нет, программные правила |

## Контроль достоверности

`review_agent` — последний рубеж, работает без LLM:

1. Каждое Evidence имеет допустимый `kind` и источник.
2. Каждое число в тексте LLM должно существовать среди Evidence.
3. **Число должно быть привязано к своей величине.** Если пересказ пишет
   «оценка Vina 2.5», а 2.5 — это IC50 из BindingDB, проверка падает.
4. При провале пересказ заменяется на перечисление измерений, факты сохраняются.

## Статусы ответа

- `success` — все запланированные шаги выполнены, ошибок нет;
- `partial` — часть собрана, часть шагов не выполнена (видно в `errors`);
- `needs_clarification` — запрос неоднозначен;
- `no_data` — источники ничего не дали;
- `error` — выполнить не удалось.

## Откуда берутся данные

В коде **нет** справочников молекул, SMILES, CID, идентификаторов мишеней и «эталонных» активностей. Это закреплено тестами `tests/test_no_hardcoded_chemistry.py`.

- **PubChem** — структура, CID, аналоги (живой PUG REST + файловый кэш).
- **BindingDB** — активности по SMILES соединения; мишень выводится из измерений.
- **ChEMBL** — активности; при недоступности API это сказано вслух, числа не подставляются.
- **RCSB PDB** — поиск структур и метаданные.
- **AutoDock Vina** — считается в этом запуске; сохранённый прогон берётся только при совпадении пары по `run_meta.json`.
- **RDKit** — дескрипторы; без RDKit возвращается ошибка, а не приблизительная оценка.

## Потоки данных

1. NL-запрос → `ResearchRequest` → `WorkflowState`.
2. Инструменты пишут в `state.evidence` (с дедупликацией) и `state.artifacts`.
3. Критик при необходимости добавляет шаг.
4. Пересказ → `review_agent` → `ResearchResult` + `agent_trace`.

## Внешние зависимости

- **Обязательные:** RDKit, сеть для PubChem/RCSB/BindingDB (есть файловый кэш).
- **Опциональные:** Ollama с `qwen2.5:7b-instruct`, бинарник Vina (`tools/bin/vina`), P2Rank, PoseBusters.
